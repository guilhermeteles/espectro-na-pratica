# Espectro na Prática

Teste político com casos concretos. A pessoa diz como se posiciona, responde cerca de 8 situações e recebe um resultado no espectro (extrema-esquerda a extrema-direita), com dois eixos: economia e costumes/segurança.

- As perguntas são adaptativas: cada resposta atualiza uma estimativa por eixo e a próxima pergunta é a que mais reduz a incerteza.
- A autodefinição inicial não entra no cálculo; só é comparada com o resultado.
- Botões para compartilhar o resultado ou só o teste no WhatsApp.
- Site estático: um único `index.html`, sem build. As perguntas ficam no array `QUESTIONS`.
